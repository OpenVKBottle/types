# openvkbottle-types

Библиотека типов и методов [OpenVK API](https://openvk.github.io/docs/openvk_engine/api/overview/) для фреймворка [**OpenVKBottle**](https://github.com/openvkbottle).

Проект основан на [vkbottle-types](https://github.com/vkbottle/types) и адаптирован для работы с OpenVK. Это отдельный проект, не являющийся официальным пакетом VKBottle.

[![PyPI version](https://img.shields.io/pypi/v/openvkbottle-types.svg)](https://pypi.org/project/openvkbottle-types/)

## Установка

Из PyPI:

```console
pip install openvkbottle-types
```

Последнюю версию из ветки `master` можно установить напрямую с GitHub:

```console
pip install -U https://github.com/openvkbottle/types/archive/refs/heads/master.zip
```

Установка из GitHub может включать изменения, которые ещё не вошли в опубликованный релиз.

## Сообщить об ошибке

Если вы обнаружили ошибку в типах или методах, создайте issue в [основном репозитории OpenVKBottle](https://github.com/openvkbottle/openvkbottle) и добавьте метку `openvkbottle-types`.

Если вы можете самостоятельно исправить проблему, буду рад pull request. При наличии соответствующего issue укажите ссылку на него в описании.
